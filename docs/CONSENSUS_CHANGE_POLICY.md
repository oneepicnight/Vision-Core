# Consensus Change Policy

This file is retained as the stable link used by the original developer
documentation.

The authoritative consensus classification, protected-subsystem,
authorization, and uncertainty rules are now defined in
[CONSENSUS_BOUNDARIES.md](CONSENSUS_BOUNDARIES.md).

The authoritative validation matrix and evidence requirements are defined in
[TESTING_POLICY.md](TESTING_POLICY.md). Release promotion and immutable-tag
rules are defined in [RELEASE_PROCESS.md](RELEASE_PROCESS.md).

Do not maintain a second copy of those rules here. Historical development
context is recorded in [DEVELOPMENT_HISTORY.md](DEVELOPMENT_HISTORY.md), and
accepted rationale is recorded under [DECISIONS](DECISIONS/README.md).
